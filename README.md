# Лабораторні роботи з аналізу даних (Python)

Розв'язання задач регресії: метод найменших квадратів, нейронні мережі (MLP), дерева рішень та ансамблеві методи.
Усі роботи виконано за **варіантом 1**.

| Робота | Тема | Скрипт |
|---|---|---|
| Лабораторна робота 1 | Побудова багатофакторної регресійної моделі методом найменших квадратів (МНК) | [`lab1/lab1_mnk.py`](lab1/lab1_mnk.py) |
| Лабораторна робота 2, частина 1 | Розв'язання задач регресії за допомогою нейронних мереж типу «багатошаровий персептрон» (MLP) | [`lab2_part1/lab2_part1_mlp.py`](lab2_part1/lab2_part1_mlp.py) |
| Лабораторна робота 2, частина 2 | Розв'язання задач регресії на базі дерев рішень, ансамблів (Random Forest, XGBoost) і нейронних мереж | [`lab2_part2/lab2_part2_trees.py`](lab2_part2/lab2_part2_trees.py) |

## Встановлення

Потрібен **Python 3.12 або 3.13**. TensorFlow поки не підтримує Python 3.14.

### Варіант 1: через uv (рекомендовано)

[uv](https://docs.astral.sh/uv/) сам встановить потрібну версію Python і всі залежності у віртуальне середовище `.venv`:

```bash
uv sync
```

### Варіант 2: через pip

```bash
python3.13 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Додатково для macOS

XGBoost потребує бібліотеку OpenMP:

```bash
brew install libomp
```

## Запуск лабораторних робіт

Команди виконуються з кореня проєкту. Якщо середовище встановлено через uv, замість `python` можна писати `uv run python`.

### Лабораторна робота 1 — метод найменших квадратів

```bash
python lab1/lab1_mnk.py
```

Модель `y = b0 + b1·x1 + b2·x2 + b3·x1·x2 + b4·x1² + b5·x2²`. Скрипт:

- реалізує МНК власною функцією: формує матрицю F і розв'язує систему нормальних рівнянь (FᵀF)·a = FᵀY методом Гаусса;
- для контролю порівнює результат з формулою a* = (FᵀF)⁻¹FᵀY;
- обчислює залишки, коефіцієнт кореляції та критерій Дарбіна–Уотсона;
- виконує контрольні приклади 1 і 2 та індивідуальне завдання (варіант 1), будує 3D-поверхню моделі.

Час виконання — кілька секунд.

### Лабораторна робота 2, частина 1 — нейронна мережа MLP

```bash
python lab2_part1/lab2_part1_mlp.py
```

- **Основне завдання:** регресія `Y = f(1ф, 2ф)` на даних варіанту 1 (файл `lab2_part1/Data.txt`). Порівнюються три архітектури MLP за крос-валідацією Leave-One-Out, найкраща навчається і застосовується до нових даних.
- **Додаткове завдання:** регресія міцності бетону на наборі UCI [Concrete Compressive Strength](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength).

Час виконання — близько 3–4 хвилин. Потрібен Інтернет для завантаження набору даних UCI.

### Лабораторна робота 2, частина 2 — дерева рішень та ансамблі

```bash
python lab2_part2/lab2_part2_trees.py
```

Набір даних UCI [Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance), цільова ознака — підсумкова оцінка учня `G3`. Етапи:

1. EDA: перевірка пропусків і викидів, кодування категоріальних ознак, розбиття 80/20.
2. Decision Tree: залежність MSE від `max_depth` (1–20), пошук точки перенавчання.
3. Random Forest і XGBoost: експерименти з глибиною, `n_estimators` та `learning_rate`.
4. Нейронна мережа (MLP), порівняльна таблиця моделей (R², MAE, RMSE), важливість ознак.
5. Інженерія ознак (нові ознаки на базі існуючих) і перевірка зміни R².
6. Прогноз усіма моделями для однакових нових даних.

Час виконання — близько 1 хвилини. Потрібен Інтернет для завантаження набору даних UCI.

## Куди зберігаються результати

Кожен скрипт виводить результати в консоль і зберігає їх у папку `output/` поруч із собою:

| Файл | Вміст |
|---|---|
| `output/*.png` | графіки (порівняння фактичних і прогнозних значень, залишки, криві навчання, 3D-поверхні тощо) |
| `output/log.txt` | повний текстовий вивід програми |
| `output/results.json` | числові результати (коефіцієнти, метрики, прогнози) |

Графіки лише зберігаються у файли й не відкриваються у вікнах під час виконання. Переглянути їх можна в папці `output/`. Під час кожного запуску файли перезаписуються.
